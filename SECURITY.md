# Security Policy

## Reporting

Use GitHub private vulnerability reporting: https://github.com/labacacia/NPS-Daemons/security/advisories/new. Do not open a public issue. Include the affected version, reproduction conditions, and impact, with secrets and unrelated data removed.

Only the latest maintained branch and latest pre-release are supported unless maintainers state otherwise.

## Scope

Services process untrusted traffic and hold keys, sessions, certificates, tasks, and persistence state. Review mTLS, admission, databases, execution, containers, and secrets.
